# کوهستان برفی ۱۹۴۲ — دمو کوچک Kübelwagen

این نسخه عمداً هیچ Branch از پیش تعیین‌شده‌ای ندارد.

کاربر هنگام قرار دادن پروژه در GitHub می‌تواند Branch اصلی را خودش انتخاب کند:
- main
- master
- یا هر نام معتبر دیگر

پروژه هیچ تنظیمی ندارد که main یا master را تحمیل کند.

## Git / GitHub
- پوشه .git داخل پروژه وجود ندارد.
- نام Branch داخل فایل‌های پروژه تعیین نشده است.
- Remote را کاربر در MGit تعیین می‌کند.
- Workflow روی همان Branch/Ref انتخاب‌شده برای اجرای Workflow اجرا می‌شود.
- فایل Workflow: .github/workflows/build-android.yml
- هنگام Run workflow در GitHub، Branch موردنظر را خود کاربر انتخاب می‌کند.

- شلیک هواپیما به خودرو
- ۵ دنده
- سرعت فقط تابع میزان گاز و دنده است و با نگه داشتن گاز خودکار بی‌نهایت افزایش پیدا نمی‌کند.
